# legacy-agents

Ploinky agents that moved out of AssistOSExplorer, AchillesCLI and proxies. Each top-level directory is one agent (`<agent>/manifest.json`), installed by Ploinky as the `legacy-agents` repository.

| Agent | Origin |
| --- | --- |
| `multimedia` | AssistOSExplorer |
| `soplangAgent` | AssistOSExplorer |
| `tasksAgent` | AssistOSExplorer |
| `webAssist` | AssistOSExplorer |
| `GPTResearcher` | AchillesCLI |
| `opencode-free` | proxies |
| `searchAgent` | proxies |
